Torn

Connect your Torn account

  1. In Torn, open Settings → API Keys and create a Custom key with profile, bars, cooldowns, travel, money, battlestats, events, notifications, jobpoints, messages, property and company profile/employees (or just use a Limited key). The categorised log needs a Full Access key.
  2. Add set TORN_API_KEY=your_key to start-cockpit.bat above the line that starts Flask.
  3. Restart the server and reload this page.
